## 👋 About Me

> **3DGS 같은 연구 단계의 3D 기술을 실제 서비스 수준으로 끌어올리는 엔지니어**를 지향합니다.

- 🔬 세종대 **Immersive Media Lab** 학부연구생으로 **3D Gaussian Splatting 품질 개선(Denoising, Key-frame Selection)** 연구
- 🏗️ 3DGS 기반 모듈형 디지털 트윈 플랫폼 **ModuTwin** 개발 → **창의설계경진대회 대상 · KCGS 우수학부포스터논문상 · 특허 출원**
- 🤖 AI Agent · LLM 경량화 대회에서 **멀티 에이전트 설계, 벡터 검색, 경량 의사결정 모델** 구현
- 📚 현재 **SK AI Leader Academy (SKALA) 4기**에서 AX 전반(MSA, Backend, Frontend)을 학습 중
